The test file builds source PDFs with `PDFDocument.create()` and feeds
their `save()` bytes back through `mergePdf`, so binary fixtures stay
out of the repo. Page count is verified across 1-of-3, 2+3 multi-doc,
empty-selection, and missing-source cases. Rotation tests pin the four
quadrants of the matrix (no source / source rotated, with / without
user rotation). The empty-selection case is pinned as "parseable PDF"
not "0 pages" because pdf-lib's load injects a placeholder page on
an otherwise-empty save; pinning that as the observed invariant
matches what UI code actually sees if it ever leaks past the export
gate.
