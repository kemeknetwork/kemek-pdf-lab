## Diff summary
A pure bytes-in→bytes-out watermark engine. `watermarkPlacements` returns
bottom-left-origin PDF-point coords for the object's lower-left corner: the 9
single-point anchors respect a 24pt default margin and center on free axes;
`tile` returns a grid stepping by object-size + 1.5×(larger dim) gap. The
geometry helper has zero pdf-lib dependency, so it's tested with plain number
assertions. `applyWatermark` loads the PDF, embeds Helvetica (text) or the
PNG/JPG (image), stamps every placement on each target page, and saves —
preserving page count exactly, defaulting to all pages, no-op on empty text,
clamping opacity. Safe in isolation: it has no callers in the app (the UI
wiring is the fenced-off human follow-up), so it cannot affect the live
export/merge path.
