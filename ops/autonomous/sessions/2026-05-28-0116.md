## Picked (and why)
The watermark engine and its tests landed earlier tonight (bde0d32), but the
two `targetIndices` tests were weak: both only asserted `getPageCount()`
survived, with a comment claiming "only pages[1] is touched here" that nothing
actually verified. A regression that stamped every page regardless of
`targetIndices`, or an off-by-one in the index loop, would pass silently. I
added a `stampedContentLengths` helper that reads each page's drawn content
stream length, then rewrote the subset tests to assert *which* pages got
stamped: `[1]` stamps only page 1, omitted = all pages, out-of-bounds = none.
I also added a test pinning that `[]` means "no pages" (not "all") — guarding
against a `targetIndices || all` refactor that would treat the empty array as
falsy. This is real logic on the most bug-prone branch, not coverage-chasing.
